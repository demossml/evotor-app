# 4.0.0 — бонусы через резервацию на сервере

- Скан QR → `POST {API_BASE_URL}/api/devices/loyalty/resolve` (через прокси Эвотора, заголовок Authorization подставляет облако Эвотора, в APK секретов нет).
- Ответ сервера (стаканы, бесплатный, кэшбэк, `reservationId`) показывается кассиру; QR не содержит баланса.
- Скидка (бесплатный стакан = самая дешёвая единица в чеке, кэшбэк) считается только при наличии резервации.
- В чек пишется `extras.sc = {v:2, c, op:reservationId, free, cb, ts}`; списание окончательно делает backend по SELL.
- Нет связи: подписанный QR всё равно попадает в чек (стакан засчитается), бонусов нет. Номер карты вручную — только начисление.
- Удалены офлайн-проверка подписи (CardTokenVerifier, ключи в сборке) и тестовые привязки.
- Скан хранится только для одного чека и очищается после события скидки.
