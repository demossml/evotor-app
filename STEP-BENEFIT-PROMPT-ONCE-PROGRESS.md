# PROGRESS — окно льготы ровно один раз

Промпт: `PROMPT-APK-FIX-BENEFIT-PROMPT-ONCE.md` · **5.2.7-prompt-once / versionCode 132**

## 1. Где показывалось окно льготы (все места до фикса)

| Место | Что показывало | Почему дублировало |
|---|---|---|
| `resolve()` → `maybePromptBenefit(info)` | «Льгота гостя» (подарок / ваучеры / без льготы) | флаг `benefitPrompted` сбрасывался **в начале каждого** `resolve()`; повторный скан того же QR (или доставка скана через `ScannerHub`) давал второй показ |
| `openLoyaltyOrSend()` → `showLoyaltySheet(...)` — вызывается по «В чек» | лист «Лояльность» (подарок / кэшбэк / ваучер / итог) | открывался автоматически перед каждой оплатой — это и был «третий» диалог |
| «Изменить льготу» внутри листа «Лояльность» | второй диалог «Льгота гостя» поверх листа | лишний вход, сброс флага вручную |

## 2. Что сделано

1. **`BenefitPromptGuard`** (`data/BenefitPromptGuard.kt`) — единственный источник решения «показывать ли окно».
   `ask(code, hasOffer)` ставит отметку **до** показа, поэтому повторный `resolve`/`safeRender`/
   переход к оплате окно не откроют. Новая карта — своя отметка. `onCardCleared()` — сброс.
2. **Единственный вход** `maybePromptBenefit(card, force, onDone)`: обычный показ — только из конца
   успешного `resolve()`; `force = true` — только явное действие кассира.
3. **Перед оплатой авто-окно убрано.** `openLoyaltyOrSend()` больше не открывает лист: считает
   `currentChoice()` и сразу отправляет в чек. Окно может показаться здесь **максимум один раз**
   и только если для этой карты оно почему-то не показывалось (`benefitGuard.ask(...)`), причём
   «Готово» сразу продолжает отправку (`onDone`).
4. **Отвязка карты сбрасывает отметку**: «Продолжить без карты», «Забыть карту», «Заменить карту»,
   «Сбросить клиента», ошибка `resolve` — все идут через `forgetCard()`.
5. **Лист «Льготность» остался, но только по явной кнопке** «Изменить льготу» в корзине
   (под блоком карты) — там же кэшбэк, который в окне после карты не предлагается.
   Ссылка «Изменить льготу» внутри листа удалена (она открывала второй диалог поверх первого).
