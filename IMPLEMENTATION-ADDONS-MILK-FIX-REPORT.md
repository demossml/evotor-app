# IMPLEMENTATION — фикс «объём есть, молока нет» (касса)

Основание: `RESEARCH-ADDONS-MILK-MISSING.md` §3.4 (K3). Версия: **versionCode 136, versionName `5.2.11-addons-milk`** (было 135 / `5.2.10-cashback-with-vouchers`).

## Что изменено
- **K3.** Новый `data/SheetToppings.kt`: добавки для листа выбора берутся у выбранного размера, а если их нет, у другого размера той же карточки (совпадение `variantGroup`). Чужая карточка донором быть не может.
- `ui/MainActivity.kt`: `showItemSheet` и `onVariantChanged` используют `SheetToppings.effective(...)`. Раньше при открытии донор был, а при смене объёма опции строились только по выбранному размеру, и секции «Молоко»/«Сироп» пропадали.
- Лог `SC_TOP volumeChanged` теперь пишет `tops=<с донором> own=<собственные>`.

Не затронуто: сканер, фискализация 1 ₽ (`SellLauncher`), `ClientOffers`/кэшбэк, `CardSession`, скрытие модификаторов (`hideFromMenu`), комбо.

## Тесты и проверка
- `app/src/test/.../data/SheetToppingsTest.kt`, 7 тестов: донор для размера без добавок; смена 250→450 и обратно; собственные добавки главнее; донор чужой карточки не используется; нигде нет добавок → пусто; `effective` возвращает тот же объект при своих добавках; донорские добавки при сохранённых uuid и цене выбранного размера.
- **Gradle-сборку и `:app:testDebugUnitTest` запустить не удалось**: в среде нет Android SDK и доступа к зависимостям Gradle. Поэтому `SheetToppings.kt`, модели данных и логика тестов скомпилированы отдельным Kotlin-компилятором 2.0.21 и выполнены напрямую: 7 из 7 прошли. Правка `MainActivity.kt` (две вставки) компилятором не проверялась, она проверена только чтением. Перед выкладкой выполните `./gradlew :app:testDebugUnitTest :app:assembleRelease`.

## Чек для терминала
1. Открыть «Капучино», переключить 200→400→200: секции «Молоко» и «Сироп» остаются.
2. `logcat -s SC_TOP`: в строках `volumeChanged` `tops>0`.
3. Подарок за 1 ₽ и окно клиента с кэшбэком/ваучером работают как в 5.2.10.

## Данные
Касса только показывает то, что отдал backend. Если у всех размеров `toppings=0` (схема не назначена), владельцу нужно назначить непустую схему карточке «Капучино»; фиксы backend из `sixth-cup-addons-milk-fix.zip` убирают ловушки админки, но схему сами не назначают.
