# SWITCH CLIENT — REPORT

- `versionCode`: **175**
- `versionName`: **5.3.16-switch-client**
- Тесты: **647 / 0**
- APK: `app/build/outputs/apk/release/app-release.apk`

## Что сделано

### Ручная смена клиента

- В блоке активной карты добавлена кнопка **«Сменить клиента»**.
- На экране карты кнопка «Отвязать» переименована в **«Сменить клиента»**.
- В меню дополнительных действий пункт «Сбросить клиента» заменён на **«Сменить клиента»**.
- После сброса:
  - `CardSession` очищается;
  - очищаются `free`, `cashback`, `cashbackKopecks`, `voucherId`;
  - очищаются `lastCardCode`/`lastCardLabel`;
  - `BenefitPromptGuard` сбрасывается;
  - открывается экран ввода телефона/QR.
- Корзина **не очищается**.

### Новый гость

- При привязке новой карты по телефону выбор льгот предыдущего гостя сбрасывается.
- `CardSession` заменяется только серверными данными нового профиля.
- Бонусы и скидки пересчитываются от новой карты или без карты.

### Автосброс после продажи

- При закрытии чека без post-pay экрана карта очищается сразу.
- На post-pay экране карта показывается для итогов, затем очищается при:
  - «К баристе»;
  - «Новый заказ»;
  - системном back.
- Ручная кнопка «Сменить клиента» доступна всегда.

### Защита от гонок

- Добавлен `cardEpoch`: старый фоновый `refresh` не может вернуть карту после сброса.
- Добавлен `resolveSeq`: ответ старого `resolve` игнорируется, если клиента уже сменили.
- `CardSession.refreshFromServer` принимает `shouldApply` и не пишет результат, если карта уже сброшена/заменена.

## Не менял

- backend, каталог, `SellLauncher`;
- процент начисления;
- маску телефона и consent-flow.
