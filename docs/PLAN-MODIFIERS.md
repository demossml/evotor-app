# План: добавки (сиропы, топпинги) к напиткам

## Сейчас (касса Эвотор)

- При добавлении **напитка** открывается диалог: сиропы / топпинги / молоко.
- Список добавок **локальный** (`ModifierCatalog` в APK) — временный seed.
- В чек: «Капучино · Ваниль» и цена с учётом добавок.
- «В чек» / «Без добавок» / «Отмена».

## Нужно в backend + admin (ещё не сделано)

| Задача | Где |
|--------|-----|
| Справочник добавок (имя, цена, группа, available) | backend + admin UI |
| Привязка к товару / категории («рецепт») | product ↔ modifiers |
| Отдавать в `GET /api/directory` | `modifiers[]`, `product.modifierIds[]` |
| Касса только с сервера | убрать локальный seed |
| Лимиты (например max 2 сиропа) | правила в admin |

### User story админа

1. Admin → «Добавки» → «Сироп ваниль» 40 ₽.
2. Товар «Капучино» → отметить доступные добавки.
3. Кассы после обновления меню видят тот же набор.

### Принцип UX

Бариста не забывает предложить добавки: лист открывается **сразу** при выборе напитка.

## Не в этой итерации

- Sticky-бар чека и сетка товаров (отдельный UX-редизайн).
