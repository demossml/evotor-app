# Добавки (сиропы, топпинги) — текущая архитектура

Справочник добавок хранится в backend 6.7. У каждого товара есть `modifier_scheme_id`.

Во время синхронизации backend включает в `ProductExtra` товара только те добавки, которые разрешены его схемой. Это предотвращает глобальный список «всех сиропов» на кассе.

На терминале APK читает `ProductExtra` по Evotor product UUID и показывает бариста рецепт и доступные именно для выбранного товара добавки.

Фискализация остаётся за Эвотором. Отдельная логика добавок не создаёт собственный каталог товаров и не использует хардкодный `ModifierCatalog`.

Ограничения вроде максимального количества добавок могут быть добавлены в metadata схемы, не меняя APK-каталог.
