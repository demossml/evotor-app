В среде нет Android SDK и доступа к Maven → **`assembleDebug` не запускался, юнит-тесты не гонялись**.

Скриншоты владельца в ТЗ **не приложены**, поэтому раскладка собрана по текстовому описанию ТЗ, а не «в пиксель» по макетам. Живой прогон на ST5 не делался.

## Как грузятся фото
`imageUrl` (backend `/api/devices/catalog`) → `ThumbLoader`: память → диск → сеть (https, ≤2 МБ). На диске «мастер» WebP ≤288 px (лимит 24 МБ, чистка по давности), в память — декод под размер view (список 128 px, «Фокус» 288 px). Полноразмерных картинок в списках нет. Загрузка в пуле из 3 потоков; при прокрутке запрос отменяется (`onViewRecycled`), неудачные URL не повторяются 5 минут. Нет фото → круг с инициалами. Выбор «свой загрузчик, а не Coil/Glide»: в проекте нужен один сценарий (https → миниатюра), без новой зависимости и роста APK; цена — собственный код (покрыт ревью, но не тестами).

## Анти-лаг и анти-overflow
- Нет полной пересборки дерева: DiffUtil, чипы создаются один раз, debounce поиска.
- Легкие ViewHolder'ы, слушатели один раз, `itemAnimator=null`, без elevation/blur на строках, без анимаций макета в bind.
- Каталог в памяти один раз, фильтрация по списку; плашки «×N» обновляются payload'ом.
- Первый показ каталога не ждёт сеть (две фазы).
- Insets + `maxLines/ellipsize` везде, горизонтальный скролл для чипов/«Фокуса», одна строка 52 dp снизу.
- Загрузка карты (resolve) и каталога — в фоне, как и раньше; StrictMode в debug.
- Бюджет «<300 мс CPU на первый показ» **не измерялся** (нет устройства); архитектурно первый кадр — это Inventory-запрос + создание ~8 ViewHolder'ов.

## Что не сделано

- Настоящее комбо (состав, цена комбо) — в API нет; сейчас метки `#combo/#focus/#old=` в описании.
- Экран «Карта гостя», «Оплата» и корзина-sheet — без визуального редизайна (вне объёма ТЗ).
- Тёмная тема, замеры на ST5, скриншот-тесты.

## Самооценка: 7,5 / 10
Структура и производительность — на уровне 8–9 (по коду), но не проверены на устройстве и не собраны; визуальное соответствие скринам владельца не подтверждено (скринов нет).
