# REPORT — скролл на экране выбора скидки/льготы

Промпт: `PROMPT-APK-FIX-DISCOUNT-SCROLL.md` · 28.10.2026 · **5.2.5-discount-scroll / versionCode 130**

## Что было (контейнер)

| Экран | Контейнер до фикса | Проблема |
|---|---|---|
| Лист «Льготa гостя» (сразу после карты) | `LinearLayout` внутри `BottomSheetDialog`: `sheetHead` → **контент** → `foot` с «Готово» | Контент без скролла: при 5+ ваучерах и блоке подарка кнопка «Готово» уезжала за экран, лист не скроллился |
| Лист «Лояльность» (перед чеком, «В чек») | тот же паттерн: `sheetHead` → **контент** → `foot` с «В чек» | То же: блок «Подарок» + «Скидка» + список ваучеров + итог не помещались, «В чек» становилась недоступной |
| Панель корзины (`showCart`), лист рекомендаций | уже `NestedScrollView` weight=1 + фиксированный foot | ок |
| Экран заказа | `bottomBar`/плавающая полоса с «В чек» — sibling каталога, не внутри скролла | ок |

## Что сделали

1. **`sheetScroll()`** — общий хелпер: контент листа кладётся в `NestedScrollView` с `isFillViewport = true` и весом 1, а `foot` остаётся sibling снизу (sticky). Применён к обоим листам выбора льготы.
2. **Листы разворачиваются на весь экран** (`STATE_EXPANDED`, `skipCollapsed = true`) — иначе у скролла нет высоты, и он не может прокрутиться.
3. **Убрана пересборка каталога после «Готово»**: `saveChoice()` уже обновляет бейджи и суммы, а `safeRender()` сбрасывал каталог в начало списка. Теперь позиция скролла не прыгает при смене «подарок/ваучер».

## Ручной чеклист (проверить на терминале)

- [ ] 5+ ваучеров в листе «Льгота гостя» — список скроллится, «Готово» на месте
- [ ] Лист «Лояльность»: подарок + скидка + ваучеры + итог — «В чек» на месте
- [ ] Смена «Подарок ↔ Ваучер» не сбрасывает каталог в начало

- [ ] Scanner (`ScannedCode`), L-00 (`sc.c` = токен), `DiscountCalc` — без изменений
