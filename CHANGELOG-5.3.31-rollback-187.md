# CHANGELOG 5.3.31 — сборка 190 = рабочая 187

## Задача

Касса на версии 188/189 перестала открывать карточку товара (модальное окно не
появляется). Эталон — APK, который работал: `app-release.apk 19.20.02`
(versionCode **187**, versionName `5.3.28-milk-defaults`).

## Что сделано

Код уже равен рабочей 187 (сравнение побайтово: `classes.dex` APK 187 и 189
совпадают полностью), поэтому изменён только номер сборки:

- `versionCode = 190`
- `versionName = "5.3.31-rollback-187"`

Сборка выполнена с `clean`, чтобы исключить влияние инкрементальных артефактов
версии 188.

## Сравнение с эталонным APK 187

| Файл | 187 | 190 |
|---|---|---|
| `classes.dex` | `89f652b8…` | `89f652b8…` (идентичен) |
| `classes3.dex` | 1 495 212 Б | 1 495 236 Б (отличие — строки версии и API-совместимая запись `paidInFlight`) |
| ресурсы (`res/**`, `resources.arsc`) | — | без отличий |
| `AndroidManifest.xml` | — | отличается только versionCode/versionName |

## Если карточка всё ещё не открывается на 190

Код в APK идентичен рабочему 187, значит причина не в коде, а в данных
приложения на терминале: версия 188 писала файл кэша конфигураций
(`ProductConfigCache`) и фоновую предзагрузку. Рекомендуется удалить данные
приложения (Настройки → Приложения → Sixth Cup → Очистить данные) и запустить
заново.
